New package: `@kingstinct/exact-healthkit` brings HealthKit to Exact apps (github.com/expo/exact). It exposes react-native-healthkit's functionality under the same names as an Exact interface with a Swift implementation for iOS: authorization, characteristics, quantity, category, correlation, workout, heartbeat series, electrocardiogram, state of mind, medication and activity summary reads, statistics and anchored queries, saves and deletes. Every read is live through HealthKit observer queries. Under Exact's agent it answers from an in-memory fixture store. Background delivery is not supported yet.
